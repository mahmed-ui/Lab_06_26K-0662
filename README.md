# Lab 06: Loops and 1D Arrays

Solutions to the Lab 06 programming tasks, written in C as part of my Computer Science coursework (Section BCS-1D).

The lab focuses on using **loops** and **one-dimensional arrays** to solve small real-world problems such as banking, ATMs, warehouses and traffic monitoring.

## Concepts Covered

- `for`, `while` and `do-while` loops
- 1D arrays (declaring, traversing, updating)
- Conditions (`if`, `else if`, `else`)
- Counting, summing and averaging
- Finding the largest and smallest values
- Digit manipulation (reversing a number)
- Strings and character functions (`islower()`, `isupper()`, `isdigit()`)
- Fibonacci pattern
